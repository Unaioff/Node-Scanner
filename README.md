# Node-Scanner

Node-Scanner es una herramienta desarrollada en Python cuyo objetivo es el descubrimiento, visualización y análisis de infraestructuras de red de forma centralizada.

La aplicación está orientada a entornos de redes privadas, facilitando la supervisión de dispositivos, servicios y nodos conectados. Proporciona información útil para tareas de administración de sistemas, diagnóstico de red y reconocimiento de infraestructura.

## Funcionalidades

- Descubrimiento de hosts en la red local
- Escaneo de puertos en dispositivos activos
- Identificación de servicios en ejecución
- Análisis básico de la infraestructura de red
- Visualización de la información obtenida (si aplica en tu proyecto)

## 📦 Instalación

Clona el repositorio:

```bash
git clone https://github.com/Unaioff/Node-Scanner.git
```

Accede al directorio del proyecto:

```bash
cd Node-Scanner
```

Instala las dependencias:

```bash
pip install -r requirements.txt
```

## USO

Ejecuta la aplicación principal:

```bash
python main.py
```
